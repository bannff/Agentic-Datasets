# Beads - AI-Native Issue Tracking

This repository uses **Beads** for local, git-native issue tracking.

## Quick Start

Initialize Beads:
```bash
bd init
```

Create an issue:
```bash
bd create "Implement new dataset transform"
```

List issues:
```bash
bd list
```

## Why Beads?

- **Git-Native**: Stored in Dolt database right in your repo.
- **AI-Friendly**: CLI-first design for seamless agent interaction.
- **Offline First**: Works without a web UI.
