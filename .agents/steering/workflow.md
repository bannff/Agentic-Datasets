# Agent Workflow

1.  **Analyze**: Read the issue from Beads or GitHub.
2.  **Plan**: Document the approach in the issue or a design document.
3.  **Implement**: Write modular code respecting the <200 LOC limit.
4.  **Verify**: Run `pytest` and `scripts/verify_repo.sh`.
5.  **Commit**: Push changes with descriptive Git messages (semantic commits).
